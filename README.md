Dit project maakte ik voor het vak Programmeren Gevorderd 1.

Voor deze opdracht moest ik:
- Steden, straten, voornamen en achternamen inlezen uit CSV- en JSON-bestanden.
- Deze gegevens opslaan in een databank.
- De opgeslagen gegevens gebruiken om een nieuwe dataset te genereren.

Voor dit project moest ik de volgende technologieën gebruiken:
- C#
- WPF
- ADO.NET
